Accessibility Statement

As someone passionate about UX design and web accessibility, making the web usable for everyone is both a professional standard and a personal commitment. I believe a truly open web must be an accessible web.

My Commitment

I have designed and built this website aiming to meet the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA standards. My goal is to ensure that anyone, regardless of technology or ability, can seamlessly navigate my portfolio, read my devlogs, and explore my projects.

What I'm Doing

To ensure a barrier-free experience, this site is built with a focus on:

  • Semantic HTML: Using clean, logical document structures optimized for screen readers and other assistive technologies.
  • Keyboard Navigation: Ensuring all links and interactive elements are fully usable without a mouse.
  • Meaningful Alternatives: Providing descriptive text for non-text content (yes, including the MapleStory Axe Stump).
  • Simplicity & Performance: A lightweight, bloat-free design that respects user preferences and loads efficiently across devices.

Feedback is Welcome

Digital accessibility is an ongoing process of learning and iterating—much like open-source development.

If you encounter any accessibility barriers while browsing this site, or if you have suggestions on how the code can be improved, I would love to hear from you. Please feel free to open an issue on my GitHub (opens in a new tab) so we can make this space better together.
